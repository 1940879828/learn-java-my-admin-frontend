# 全局用户名水印 设计文档

- 日期：2026-05-15
- 作者：YeJpeChen（与 Claude 协作）
- 状态：已确认

## 背景与目标

后台系统涉及用户、角色、菜单等敏感信息。为了便于截图溯源、抑制未授权外传，需要在登录后的所有后台页面叠加当前用户名水印。

目标：

- 登录用户在浏览任意后台页面时，页面上叠加当前用户名水印。
- 未登录页面（登录页等）不显示水印。
- 改动最小，不影响现有布局、主题、路由逻辑。

非目标（YAGNI）：

- 不展示日期、IP、角色等附加信息。
- 不提供水印样式自定义（颜色/字号/角度/密度等）的配置项。
- 不为未登录场景设计占位水印。

## 方案

### 实现位置

在 `src/layouts/AdminLayout.tsx` 内，使用 antd 自带的 `<Watermark>` 组件包裹 `<ProLayout>`。

由于路由分层已将"登录后页面"放在 `AdminLayout` 下，未登录页面（`/login` 等）走 `BlankLayout`，天然不会渲染水印。无需在 `App.tsx` 顶层添加，也无需写未登录分支判断。

### 水印内容

`content` 取 `useUserStore` 中的 `user?.username`。`AdminLayout` 已经从 store 读取了 `user`，无需新增数据获取逻辑。

### 包裹粒度

包裹整个 `<ProLayout>`（而非仅 `<Outlet />`），让侧边栏与顶栏区域的截图也带水印，溯源更完整。

### 样式

使用 antd `Watermark` 的默认样式（默认对角排列、半透明灰色文字），不传自定义参数。后续若需要调整再按需扩展。

## 改动范围

| 文件 | 变更 |
| --- | --- |
| `src/layouts/AdminLayout.tsx` | 新增 `Watermark` 导入；用 `<Watermark content={user?.username}>` 包裹 `<ProLayout>` 返回值 |

无新增文件，无 store / 路由 / 类型变更。

## 设计取舍

- **为什么不放在 `App.tsx`**：放顶层需要额外写"未登录不渲染"的条件判断；放 `AdminLayout` 利用现有路由分层即可达成同样效果，零额外分支，更简洁。
- **为什么不抽象成独立组件**：当前只有一处使用，不需要抽象。若未来在多个布局中复用再提取。
- **为什么不做样式配置**：当前需求只要"显示用户名水印"，样式配置属于过度设计，违反 YAGNI。

## 验收标准

1. 登录后访问任意后台页面（如 `/user`、`/role`、`/menu`、`/profile`），页面叠加显示当前用户名水印。
2. 访问 `/login` 不显示水印。
3. 切换用户重新登录后，水印内容随之更新。
4. 暗黑模式下水印仍可见，无明显视觉异常（使用 antd 默认即可，由 antd 主题处理）。
5. 现有功能（菜单、表格、抽屉、主题切换等）行为不变。
